# Security

Sky Mobile Interaction Lab is an engineering lab with no network, authentication, persistence, secrets, or platform-permission behavior.

Report suspected repository vulnerabilities privately to the repository owner rather than publishing exploit details in an issue.

If this lab grows to include remote APIs, deep links, secure storage, device permissions, notifications, authentication, or release signing, those features require dedicated threat modeling, platform-specific validation, dependency review, and device/simulator tests before the repository can be promoted beyond ENGINEERING LAB status.
